# 功率与限电定义

设备额定功率为kW。遥测kW与MW统一为kW，辐照度为W/m²。样本时刻须带偏移，统一UTC。记录代表自采样时刻起600秒的左值保持区间，超过600秒不外推，缺测保持未定。
每台设备重叠或相邻限电事件先求并集，再按遥测及有效期边界切分半开区间。样例INV-A的10:00–10:20及10:10–10:30合并为30分钟，不能重复积分重叠10分钟。
基线只采用同区域、同采样时刻、同100W/m²辐照档、健康且不处于限电中的参考逆变器；至少2台。对参考功率按各自额定功率归一，取中位数再乘目标额定功率，基线不超过目标额定功率。无合格对照返回NO_REFERENCE及null损失，不填0。
片段级分别记录正向损失 max(基线−实际,0)×秒数/3600 与负向偏差 max(实际−基线,0)×秒数/3600；实际高于基线的片段损失为0，但超发不被丢弃。计算保留Decimal精度，汇总后统一保留0.0001kWh；未定时长单独展示，不并入已确定损失。

事件级净结算按同一设备、同一限电并集区间汇总：净偏差=正向损失−负向偏差，净结算=max(净偏差,0)，净偏差为负时其余额列为未冲抵超发。负向偏差只冲抵本事件的 正向损失，不跨事件结转，也不产生负损失。事件定稿须在展示精度上同时闭合 基线电量−实际电量=净结算−未冲抵超发 与 正向损失−负向偏差=净偏差；无法闭合或含未定片段（缺测、无合格对照、目标故障）时整个事件保持未定，不用部分片段冲抵后少算受限时段。

清批INV-A基线100kW、实际60kW、并集30分钟：正向损失20kWh、负向偏差0、净结算20kWh；INV-B基线50、实际30、20分钟：正向损失6.6667kWh、净结算6.6667kWh。事件合计正向损失26.6667kWh、净结算26.6667kWh。若INV-A前10分钟实际110kW、后20分钟60kW，则正向损失13.3333kWh、负向偏差1.6666kWh、净结算11.6667kWh，偏差来源逐片段可查。

事件定稿按设备+并集UTC起止（epoch秒）生成事件键，与事件编号和批次无关。同一事件同一结果重复提交只复用最新定稿，不新增；结果变化时叠加新版本并把旧版标为已替换但保留；事件转未定或切换样例失败时不写入也不删除既有定稿。定稿记录采用的基线口径、基线电量、实际电量、正向损失、负向偏差、净结算与未冲抵超发，并与偏差来源、能量四账、归档包内的settlement.json互相解释。

同设备同一时刻不同观测全部隔离；同值重复观测保留稳定编号。封存需无隔离、无未定片段且所有事件已结算。此工具供离线复算，不包含生产控制或电网调度。
